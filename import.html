Import data.json ke Firestore

Halaman ini membaca data.json dari folder yang sama dan menuliskannya ke collection paket_konstruksi di Firestore. Jalankan sekali saja — menjalankannya berulang akan membuat data duplikat kecuali data lama dihapus dulu.

Halaman ini butuh login (mengikuti Security Rules Firestore). Login dulu lewat login.html kalau belum.
